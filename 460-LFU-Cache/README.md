# LeetCode 460 - LFU Cache

LeetCode problem link: https://leetcode.com/problems/lfu-cache/

Brief
- Implement a data structure for Least Frequently Used (LFU) cache.
- Support `get(key)` and `put(key, value)` in O(1) average time.

This folder contains a C++ implementation: `LFU-Cache.cpp`.

Usage
- Compile with a C++17-compatible compiler, e.g.:

  g++ -std=c++17 LFU-Cache.cpp -O2 -o lfu

- Run the produced binary and test with sample inputs or unit tests.
