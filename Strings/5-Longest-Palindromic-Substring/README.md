# LeetCode 5: Longest Palindromic Substring

Official problem link: https://leetcode.com/problems/longest-palindromic-substring/

## Problem
Given a string `s`, return the longest palindromic substring in `s`.

## Solution
Implementation is provided in `Longest-Palindromic-Substring.cpp`.

## Notes
- Use center expansion or dynamic programming to find the longest palindrome.
- Time complexity can be optimized to O(n^2) for standard solutions.
- There is also a linear time algorithm using Manacher's algorithm.
