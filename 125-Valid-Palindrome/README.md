# LeetCode 125 - Valid Palindrome

LeetCode problem link: https://leetcode.com/problems/valid-palindrome/

Brief
- Determine whether a given string is a palindrome, considering only alphanumeric characters and ignoring cases.

This folder contains a C++ implementation: `Valid-Palindrome.cpp`.

Usage
- Compile with a C++17-compatible compiler, e.g.:

  g++ -std=c++17 Valid-Palindrome.cpp -O2 -o valid_palindrome

- Run the produced binary and test with sample inputs.
